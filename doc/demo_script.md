## 开场（30 秒）— 展示 Slide 1（标题页）

大家好，我是 ReviewPilot 的开发者。

ReviewPilot 是一个 AI 驱动的 GitHub PR 代码评审助手。开发者提交 PR 后，它会自动拉取代码变更，用 AI 进行安全、逻辑、性能、风格四个维度的深度分析，然后在 PR 里创建行级评论和总结报告。同时提供一个 Web Dashboard，让团队跨仓库查看评审数据。

下面我为大家演示。

---

## 第一部分：问题背景（40 秒）— Slide 2（痛点）

先说为什么要做这个项目。

代码评审是软件质量的守门员，但实际团队中面临四个痛点：
- 高级开发者评审带宽有限，PR 排队成为交付瓶颈
- 新人 PR 反复修改，沟通成本高
- 评审标准因人而异，缺乏一致性
- 安全漏洞和性能问题人工容易遗漏

ReviewPilot 的解决思路：用 AI 做第一轮初审，让人类评审者聚焦在高价值决策上。

---

## 第二部分：系统架构（1 分钟）— Slide 3（架构）

**【按 → 切换到 Slide 3】**

系统架构分三层：
- 最上层是 GitHub，负责发送 Webhook 事件
- 中间是 FastAPI 服务，包含事件路由和 REST API
- 核心是 AI 引擎，采用**两阶段分析**

阶段一用 deepseek-v4-flash 快速总结变更，阶段二用 deepseek-v4-pro 并行做安全、逻辑、性能、风格四类深度分析。

为什么分两阶段？因为如果对每个 PR 都用最强模型全量分析，成本和延迟太高。先用便宜快速的模型做初筛，再对高风险区域做深度分析。

---

## 第三部分：AST 规则引擎（40 秒）— Slide 4（AST + AI）

**【切换到 Slide 4】**

除了 AI 分析，ReviewPilot 还内置了 AST 确定性规则引擎。

Python 10 条规则，Java 8 条规则，覆盖 SQL 注入、命令注入、不安全反序列化、硬编码密钥、资源泄漏等。

为什么需要 AST？因为 AI 有幻觉风险，可能漏掉确定性安全问题。AST 做精确语法检测，AI 做上下文理解，两者互补。

每个规则都有"不应触发"的测试用例，比如 SQLAlchemy ORM 调用不会被误报为 SQL 注入。

## 第五部分：手动 /review 命令（40 秒）— 实际操作

**【在同一个 PR 评论区输入 /review】**

除了自动触发，评审者也可以手动触发。输入 `/review` 发送。

**【等待并刷新】**

Bot 解析命令后重新执行分析。

还可以加参数，比如 `/review focus:security` 只看安全问题。这个功能做了权限控制——只有仓库协作者才能触发。

## 第六部分：Web Dashboard（3 分钟）— Slide 6 + 实际操作

**【切换到浏览器，打开 http://127.0.0.1:8000】**

### 6.1 OAuth 登录

首先看到登录页面。使用 GitHub OAuth 认证，点击后跳转 GitHub 授权，回来就登录了。整个过程用 state 参数防 CSRF，session cookie 设置了 httpOnly 和 SameSite。

### 6.2 Dashboard 统计

**【登录后展示首页】**

上面四个统计卡片——总评审数、问题总数、活跃仓库、平均问题/PR。

**【切换到 /dashboard 页面，展示图表】**

### 6.3 评审记录

**【点击 Reviews】**

评审记录列表，支持按状态筛选，分页浏览。点击一条记录，可以看到所有问题的详细信息——文件路径、行号、严重级别、修复建议。

### 6.4 增强视图

**【点击 Enhanced View】**

增强详情视图——左边代码变更、右边按文件分组的问题列表。点击问题展开查看详情。

### 6.5 仓库配置

**【点击 Repositories → Config】**

这里可以：开启/关闭自动评审、选择检查类别、设置忽略规则（比如忽略 test 文件）、调整灵敏度（High/Medium/Low）。每个仓库独立配置。

## 第七部分：误报控制（30 秒）— Slide 7（False Positive）

**【切换到 Slide 7】**

ReviewPilot 的误报控制策略：默认保守。

默认只报告高置信度（≥80%）的问题。分三级：
- Critical 必报
- Warning 报告但可关闭
- Suggestion 默认关闭

管理员可以在 Dashboard 里调整灵敏度，或添加忽略规则。

设计理念：企业场景下，误报比漏报更伤害信任。保守策略建立信任后，用户可自行调高灵敏度。
